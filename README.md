# Kort downloads

Pick the folder for your system. The file name says the platform, so you can tell them apart.

| System | File | Notes |
|---|---|---|
| Windows 10/11 (64-bit) | `windows/Kort-0.1.0-windows-x64-portable.exe` | Double-click. No install. SmartScreen may warn: More info, then Run anyway. |
| macOS, Apple Silicon (M1 or newer) | `mac/Kort-0.1.0-mac-arm64.zip` | Unzip, drag Kort to Applications. Unsigned: right-click, Open the first time. |
| macOS, Intel | `mac/Kort-0.1.0-mac-x64.zip` | Same steps as above. |
| Linux (64-bit) | `linux/Kort-0.1.0-linux-x86_64.AppImage` | `chmod +x` the file, then run it. |

Not sure which Mac you have? Apple menu, About This Mac: "Chip: Apple M…" means arm64, "Processor: Intel" means x64.

All builds are unsigned and have not yet been tested on real machines. Your data is stored locally in the app.
